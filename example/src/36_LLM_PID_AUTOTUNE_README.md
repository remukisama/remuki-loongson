# LLM 自动PID调参 Demo 使用说明

## 概述

本 Demo 配合 [llm-pid-tuner](https://github.com/KINGSTON-115/llm-pid-tuner) 使用，通过大语言模型自动优化智能车的速度环PID参数。

## 文件说明

- `36_lq_llm_pid_autotune_demo.cpp` - 龙芯端固件，负责：
  - 电机PID控制
  - 编码器速度采集
  - 串口数据上报（CSV格式）
  - 接收并应用LLM返回的新PID参数

## 串口数据格式

### 上报格式（龙芯 → 上位机）

```
timestamp_ms,setpoint,input,pwm,error,p,i,d
```

| 字段 | 说明 | 示例 |
|------|------|------|
| timestamp_ms | 时间戳（毫秒） | 5000 |
| setpoint | 目标速度 (m/s) | 1.50 |
| input | 当前速度 (m/s) | 1.23 |
| pwm | PWM输出 | 4500.00 |
| error | 误差 | 0.27 |
| p | 当前P参数 | 1800.0 |
| i | 当前I参数 | 35.0 |
| d | 当前D参数 | 0.0 |

### 接收格式（上位机 → 龙芯）

```
SET P:xxx I:xxx D:xxx
```

示例：
```
SET P:2000.0 I:40.0 D:0.0
```

## 安全注意事项

1. **急停开关**：必须准备好，调参时随时可能失控
2. **低速测试**：先在低速（0.5 m/s）下测试
3. **有人值守**：全程有人看管
4. **记录参数**：保存每次调参的结果
5. **渐进调整**：不要一次性大幅修改参数

## 参数范围建议

根据你当前的参数：

| 参数 | 当前值 | 建议范围 | 说明 |
|------|--------|----------|------|
| P | 1800.0 | 0-5000 | 速度环比例项 |
| I | 35.0 | 0-200 | 速度环积分项 |
| D | 0.0 | 0-100 | 速度环微分项 |

## 故障排除

### 1. 串口连接失败

```bash
# 检查串口设备
ls /dev/ttyUSB*

# 检查权限
sudo chmod 666 /dev/ttyUSB0

# 测试串口
minicom -D /dev/ttyUSB0 -b 115200
```

### 2. 数据格式错误

确保龙芯端输出的CSV格式正确，每行8个字段，用逗号分隔。

### 3. LLM响应超时

增加 `LLM_REQUEST_TIMEOUT` 的值（建议180秒）。

### 4. PID参数不更新

检查串口接收是否正常，确保格式为 `SET P:xxx I:xxx D:xxx`。
