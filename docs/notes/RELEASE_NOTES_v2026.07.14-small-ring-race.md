# v2026.07.14-small-ring-race

## 版本定位

这是基于 2026-07-14 实车全赛道验证结果整理的小环岛纯竞赛版。保留当前已经验证的巡线、十字和小型左右环岛控制参数，不包含大环岛适配承诺。

## 主要变化

- 保持环岛、十字等元素识别开启，避免把“静默运行”错误等同于“无元素运行”。
- 增加独立的纯竞赛静默开关，关闭 8080 端口转向遥测、8081 端口 JPEG 图传、环岛过程日志以及本地竞赛帧采集。
- 保留启动信息和相机、IMU、编码器、看门狗等故障安全提示。
- 环岛控制器继续放在独立源文件中，主循环只保留配置门控。

## 实车验证

- 连续运行 60 秒，未触发速度或丢线保护。
- 普通 U 型弯的右环候选能够超时撤销。
- 环岛前急弯未再误识别为环岛。
- 真实小左环岛完整经过入口、环内、出口及状态释放。
- 十字路口检测锁定和出口释放正常。
- 后续大弯保持普通巡线状态，没有再次误触发环岛。

## 使用与限制

- 默认纯竞赛模式：`car_config::kCompetitionQuietMode = true`。
- 如需恢复赛道调试，将该值改为 `false` 后重新编译；无需关闭元素处理。
- 当前版本面向已经验证的小型左右环岛。大环岛方案已按本轮需求舍弃，不建议直接用于大半径环岛。
- 板端安全保护仍然有效；静默模式不屏蔽故障提示。
